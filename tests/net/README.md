# Сетевые тесты (будущее)

Харнесс уже умеет открывать несколько клиентов: `client({ name: 'host' })`, `client({ name: 'guest' })`.
Когда появится кооператив (вариант B — хост-игрок), сюда ложатся сценарии вида:

1. Хост создаёт комнату, гость подключается по коду → оба видят друг друга за ≤ 3 с.
2. Хост убивает врага → у гостя враг исчезает, у обоих одинаковый счёт.
3. Гость стреляет по боссу → HP босса у хоста падает (хост — авторитет).
4. Хост закрывает вкладку → гость получает «хост отключился», игра не падает.

Каждый сценарий — файл `tests/suites/5x-net-*.mjs` с тем же форматом `export const tests = [...]`.
Для CI сигнальный сервер поднимается в `tests/net/server.mjs` на localhost.
