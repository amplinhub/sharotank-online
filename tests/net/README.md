# Сетевые тесты

Харнесс открывает несколько клиентов: `client({ name: 'host', net: sig.cfg })`, `client({ name: 'guest', net: sig.cfg })`.
Сигналинг в тестах — локальный (`tests/net/server.mjs`, `startSignaling()`), PeerJS-облако не трогаем.

Готово (`tests/suites/50-net-lobby.mjs`, этап 1):
1. Гость входит по коду, оба видят друг друга.
2. Готовность → старт → оба на арене.
3. Хост ушёл → гость видит «Хост отключился», возвращается в меню.
4. Гость ушёл → хост остаётся в комнате.
5. Ошибки: неверный и нерабочий код, сервер недоступен, сервер завис (≈10 с).

Дальше (по мере этапов 3–5):
- Хост убивает врага → у гостя враг исчезает, у обоих одинаковый счёт.
- Гость стреляет по боссу → HP босса у хоста падает (хост — авторитет).
- Разрушение вокселей доходит до гостя событиями.
- Обрыв хоста посреди боя: гость не падает.
