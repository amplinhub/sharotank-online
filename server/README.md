# Сервер комнат для Шаротанк Онлайн

Нужен только для первого «рукопожатия»: как игроки нашли друг друга по коду. Игровые данные идут напрямую между браузерами.
Публичное облако PeerJS (`0.peerjs.com`) в части сетей заблокировано, поэтому у игры должен быть свой сервер.

## Свой VPS (Ubuntu/Debian) — основной путь, одна команда
Нужны: VPS (хватит 1 vCPU и 512 МБ–1 ГБ) с Ubuntu 22.04/24.04, открытые в файрволе провайдера порты **80 и 443**.
1. Зайди на сервер: `ssh root@IP-адрес` (с телефона — Termius).
2. Запусти установщик:
   ```
   curl -fsSL https://raw.githubusercontent.com/amplinhub/sharotank-online/main/server/install.sh | bash
   ```
   Он сам поставит Docker, скачает код, определит домен, запустит сервер и дождётся сертификата HTTPS.
   Домен без регистрации: `<IP-через-дефисы>.sslip.io` (например `1-2-3-4.sslip.io`). Свой домен: `... | bash -s -- tank.example.com` (запись A на IP сервера).
3. В конце скрипт напишет «ГОТОВО» и адрес. Открой его в браузере телефона по Wi-Fi и по мобильному интернету: покажется короткий JSON.
4. Пришли адрес в чат: он вписывается в `src/net/config.js` (`host`).

Про sslip.io: бесплатно и без регистрации, но у этого домена общий лимит сертификатов Let's Encrypt на всех пользователей. Если скрипт пишет про «too many certificates» или адрес не открывается в твоей сети, купи любой дешёвый домен и перезапусти установщик с ним.
Обновление: `cd /opt/sharotank-online && git pull && cd server && docker compose up -d --build`. Логи: `docker compose logs -f`.

## Запуск на Render (бесплатно, запасной вариант)
1. Зайти на render.com, войти через GitHub.
2. **New → Blueprint**, выбрать репозиторий `sharotank-online`. Render сам прочитает `render.yaml` из корня.
3. Дождаться зелёного статуса (несколько минут). Скопировать адрес вида `sharotank-signaling.onrender.com`.
4. **Проверка до подключения к игре:** открыть `https://<адрес>/` в браузере телефона по Wi-Fi и по мобильному интернету. Должен показаться короткий JSON с текстом «PeerJS Server». Не открывается — хостинг в вашей сети недоступен, нужен другой.
5. Вписать адрес в `src/net/config.js` (`host`), закоммитить и запушить — игра пойдёт на ваш сервер.

Render, как и любой хостинг, может быть недоступен из твоей сети: проверь шаг 4 до всего остального.

Бесплатный тариф засыпает после ~15 минут без запросов и просыпается около минуты, поэтому первое «Создать комнату» может идти долго (игра ждёт сервер до 30 с, потом повторите). Пока комната открыта, сервер не спит.

## Любой другой хостинг / VPS
```
cd server && npm install && PORT=9000 node server.mjs      # либо docker build -t sharotank-signaling server
```
Снаружи нужен **https/wss** (игра открывается с https), поэтому перед сервером ставят прокси с сертификатом (Caddy, nginx) или берут хостинг, который делает это сам. Сервер слушает IPv4 (`HOST` меняет адрес), порт из `PORT`.

## Локально
`PORT=9100 node server/server.mjs`, затем игра с `?sig=127.0.0.1:9100` в адресе.
