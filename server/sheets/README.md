# Сервер «Онлайн рейтинга» на Google Таблицах

Пилоты, общий рейтинг, друзья, сообщения и посылки лома хранятся в Google Таблице
(листы **Pilots** и **Messages** создаются сами при первом запросе), а отвечает игре веб-приложение Apps Script,
привязанное к этой таблице. Старые листы v1 (Players, Records, Challenges, Parcels) больше не используются — их можно удалить.

## Развернуть впервые (~3 минуты)
1. Открой таблицу → **Расширения → Apps Script**.
2. Удали всё в `Код.gs` и вставь целиком содержимое `server/sheets/Code.gs`. Сохрани (Ctrl+S).
3. **Развертывание → Новое развертывание** → шестерёнка → **Веб-приложение**: выполнять как **Я**, доступ **Все**.
4. **Развернуть** → разрешить доступ к таблице («Дополнительно» → «Перейти к проекту» → «Разрешить»).
5. Адрес веб-приложения (оканчивается на `/exec`) — в `src/net/config.js` (`SHEETS.url`).

Проверка: `<URL>?a=ping` в браузере → `{"ok":true,"ver":2}`.

## Обновить код сервера (адрес не меняется)
Правится `core.js` (логика) и `gas.js` (обёртка Apps Script), затем `node tools/build-gas.mjs` собирает `Code.gs`.
В Apps Script: вставить новый `Code.gs` → **Развертывание → Управление развертываниями → ✎ (карандаш) → Версия: «Новая версия» → Развернуть**.

## Как устроено
- Все запросы — GET `…/exec?a=<действие>&…`, ответ JSON `{ok:true,…}` / `{ok:false,err}`.
- Вход: позывной (уникален без учёта регистра) + PIN из 4 цифр. В таблице только SHA-256 от `id:PIN`. 5 неверных PIN подряд — блок на 10 минут.
- Действия: `ping`, `reg`, `login`, `top`, `card` (без входа; с входом карточка дополнительно отдаёт переписку и признак «в друзьях»),
  `sync` (мои счётчики вверх, входящие вниз), `friend`, `send` (с входом).
- Очки = уничтоженные враги + 50 × медали. Счётчики только растут (несколько устройств: после входа игра берёт максимум).
- Писать и слать лом можно только тем, кого отметил ☆. Сообщение до 50 символов, до 60 в сутки; лом 10–1000, до 5 посылок в сутки.
  Сообщения старше 7 дней удаляются при синхронизации.
- Записи идут под `LockService`. Защиты от читеров почти нет (данные приходят из браузера) — это игра для друзей.
- Тесты: `tests/net/sheets-mock.mjs` крутит ту же логику `core.js` в памяти, набор `tests/suites/40-drivers.mjs`.
