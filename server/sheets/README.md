# Сервер «Водителей» на Google Таблицах

Рекорды по боссам, вызовы, посылки и карточки водителей хранятся в таблице
**«Шаротанк Онлайн — Водители»** (листы Players, Records, Challenges, Parcels), а отвечает игре
веб-приложение Apps Script, привязанное к этой таблице.

## Развернуть (один раз, ~3 минуты)
1. Открой таблицу → **Расширения → Apps Script**.
2. Удали всё в `Код.gs` и вставь целиком содержимое `server/sheets/Code.gs`. Сохрани (Ctrl+S).
3. **Развертывание → Новое развертывание** → шестерёнка → **Веб-приложение**.
   - Описание: `Водители v1`
   - Выполнять как: **Я**
   - У кого есть доступ: **Все**
4. **Развернуть** → Google попросит разрешить доступ к таблице («Проверить разрешения» → свой аккаунт →
   «Дополнительно» → «Перейти к проекту» → «Разрешить»).
5. Скопируй **URL веб-приложения** (оканчивается на `/exec`) и пришли Claude — он впишет его в `src/net/config.js`
   (`SHEETS.url`). До этого проверить можно так: открыть игру с `?sheets=<URL>` в адресе.

Проверка: открой `<URL>?a=ping` в браузере — должно прийти `{"ok":true,"ver":1}`.

## Обновить код сервера
Правится `core.js` (логика) и `gas.js` (обёртка Apps Script), затем `node tools/build-gas.mjs` собирает `Code.gs`.
В Apps Script: вставить новый `Code.gs` → **Развертывание → Управление развертываниями → ✎ → Версия: новая → Развернуть**.
Адрес `/exec` при этом не меняется.

## Как устроено
- Все запросы — GET `…/exec?a=<действие>&…`, ответ JSON `{ok:true,…}` / `{ok:false,err}`.
- Игрок регистрирует позывной: игра создаёт случайные `id` и секретный `key` (хранятся в браузере), в таблице лежит только SHA-256 ключа.
  Писать от имени игрока без его ключа нельзя. Позывной уникален без учёта регистра.
- Действия: `ping`, `reg`, `top`, `getCard`, `chList` (без ключа) и `rec`, `chNew`, `chTry`, `send`, `inbox`, `card` (с ключом).
- Ограничения: посылки — лом 50–500, ремкомплект, ящик патронов, не больше 5 в сутки; открытых вызовов — до 5, вызов живёт 14 дней;
  карточка — до 4000 символов. Записи идут под `LockService`, параллельные запросы ждут друг друга.
- Защиты от читеров почти нет (данные приходят из браузера) — это игра для друзей.
- Тесты: `tests/net/sheets-mock.mjs` крутит ту же логику `core.js` в памяти, набор `tests/suites/40-drivers.mjs`.
