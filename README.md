# Шаротанк Онлайн

Воксельная танковая игра (Three.js). Играть: GitHub Pages этого репозитория.

```bash
npm ci
npx playwright install chromium   # один раз, для тестов
npm run dev                       # http://localhost:5173
npm test                          # автотесты
npm run build                     # dist/ + dist-single/index.html
```
Правила разработки — `CLAUDE.md`.
